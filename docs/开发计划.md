# 开发计划

## 当前里程碑

目标是交付 Mac 优先的本地可运行版本，验证完整核心闭环，不在首轮实现云同步和真实端侧模型推理。

当前工程已完成首个可运行开发版：浏览器预览可完整体验核心页面与本地数据闭环，Tauri 2 桌面壳、SQLite 接口、知识库运行层和转写 Provider 接口已建立。

## 第一阶段任务

1. [x] 建立 React + Tauri 2 工程。
2. [x] 实现首页、表达工作台、面试专区、训练计划、录音与报告、设置六个一级入口。
3. [x] 实现独立会话、本地持久化和历史回溯。
4. [x] 接入首版知识库，完成本地词语规则匹配与可解释标注。
5. [x] 建立本地转写和在线转写统一接口，首轮使用可替换的演示适配器。
6. [x] 完成生产构建、单元测试和浏览器端桌面/窄屏交互验证。
7. [ ] 在 macOS 真机完成 Tauri 打包验证。
8. [ ] 接入 whisper.cpp 并用固定中文测试集完成准确率基准。
